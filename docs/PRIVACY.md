# Privacy

ClariWord is built so that the honest version of this document is short.

## What is sent when you look something up

With default settings, a lookup transmits exactly three things to the backend
you configured:

1. the text you highlighted,
2. the sentence it appears in,
3. the sentence before and the sentence after it.

Nothing else. In particular:

- **The page URL is never transmitted.** Not the path, not the query string, not
  with page metadata enabled. Query strings routinely carry session and user
  identifiers, so the URL is excluded by construction — see
  `buildOutgoingContext` in `src/services/ai-service.ts`, which is the only
  function in the codebase that prepares page text for the network.
- **Page title and domain are off by default.** Turning them on sends the title
  and the bare domain (`example.com`), which help with jargon — "bank" means
  different things on a finance site and a river-walk blog.
- **Neighbouring sentences can be turned off** if you would rather send less, at
  some cost to disambiguation.
- Selections are capped (default 1200 characters, hard limit 4000). Longer ones
  are refused before anything is sent, not truncated silently.

Settings shows you a sentence describing exactly what your current settings will
transmit. It is generated by calling the same function that builds the request,
so it cannot describe something other than what actually happens.

In **Demo mode** — the default — nothing is sent anywhere at all. There are no
network requests.

## What is stored, and where

Locally in your browser, via `chrome.storage`:

| Data | Area | Why |
| --- | --- | --- |
| Saved vocabulary: word, meanings, pronunciation, the sentence you met it in, and the page title/URL if you left that on | `local` | The product is remembering words in the context you found them |
| Encounter history per word (up to 25, with sentence and date) | `local` | "You've encountered this 3 times" |
| Review schedule and outcomes | `local` | Deciding what to show you next |
| Daily counts: lookups, saves, reviews | `local` | The numbers in the popup |
| Your settings | `sync` | So they follow you between your own Chrome profiles |

Saved source pages are stored because the whole idea is to show you where you
met a word. Turn off **Save the source webpage with vocabulary** and entries keep
the sentence but not the page.

## What is never collected

- No browsing history. ClariWord sees only what you highlight.
- No analytics, telemetry, crash reporting or usage pings of any kind.
- No account, no identifier, no cookie. The extension does not know who you are.
- No page content beyond the selection and its immediate neighbours — the
  extension never reads or transmits a whole page.
- No audio, unless you press record on the practice page, and then only if you
  also press score with a backend configured.

## Your data, in your hands

Settings → **Export JSON** downloads everything ClariWord has stored about you,
in a readable format. Settings → **Clear saved data** deletes the vocabulary and
all statistics immediately and irreversibly; settings are kept, and can be reset
separately.

## Permissions

ClariWord requests `storage`, `contextMenus`, `activeTab` and `scripting`, and
runs its content script on `http`/`https` pages (excluding the Chrome Web
Store). It does **not** request the `tabs` permission, so it cannot read the URLs
of your open tabs.

Access to your backend's host is an **optional** permission, requested from the
Settings page when you point ClariWord at a server, for that host only.

The microphone is requested by the pronunciation practice page, which is part of
the extension and has its own origin. Recording never happens on the sites you
read, and the permission prompt names ClariWord rather than the page you are on.

## Third parties

The extension talks to one server: the backend URL you enter. There is no
default backend and no vendor endpoint baked in. Whatever that server does with
a request is determined by you — if you run the included reference backend, it
forwards the fields above to the AI provider you configured and stores nothing.
